# Fonts

This design system uses **Petrona** and **Outfit**, both loaded from Google Fonts via the `@import` at the top of `colors_and_type.css`.

- **Petrona** (variable serif, 100–900 + italics) — wordmark, display, headings.
- **Outfit** (variable sans, 100–900) — UI, body, buttons, labels.

Both are open-source (SIL Open Font License) and are the actual production fonts used in the Benchlot codebase. **No substitution was applied.**

To bundle offline, download TTF/WOFF2 from:
- https://fonts.google.com/specimen/Petrona
- https://fonts.google.com/specimen/Outfit

and place them in this folder with a matching `@font-face` block.
