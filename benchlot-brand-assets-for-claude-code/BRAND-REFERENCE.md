# Benchlot Brand Reference

## Name
**Benchlot** — capital B, lowercase everything else. One word.

## Taglines
- Primary: **The woodworker's marketplace.**
- Secondary (merch, social, ads): **Still sharp.**

## Domain
benchlot.com

## Colors
| Name       | Hex       | Usage |
|------------|-----------|-------|
| Spruce     | `#1a3030` | Primary brand. Wordmark, headings, secondary buttons |
| Bone       | `#f2f0eb` | Page background. NEVER use pure white (#fff) |
| Honey      | `#d4aa60` | Accent. CTA buttons, pricing, links, highlights |
| Dark Teal  | `#0c1c1e` | Dark tone. Nav bg, dark sections, button text on honey |

## Typography
- **Display/Wordmark:** Petrona, weight 900 (Black)
- **Body:** Outfit, weights 400–700

## Wordmark
The wordmark is "Benchlot" set in Petrona Black (900 weight) with `letter-spacing: 0.02em`. Three color variants provided:
- `benchlot-wordmark-spruce.svg` — for use on light (Bone) backgrounds
- `benchlot-wordmark-bone.svg` — for use on dark (Spruce/Dark Teal) backgrounds
- `benchlot-wordmark-honey.svg` — accent variant

## Favicon
The "B" from Petrona Black. Two variants:
- `favicon.svg` — Spruce on transparent (light mode)
- `favicon-dark.svg` — Bone on transparent (dark mode)

## OG Image
`og-image.svg` — Benchlot wordmark in Bone + tagline in Honey on Dark Teal background. 1200×630.
